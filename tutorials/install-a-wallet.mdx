A wallet is a free, secure app that holds your money securely. You need one to use Neko. Pick one based on how you want to use Neko most often.

## Pick a wallet

<CardGroup cols={2}>
  <Card title="Freighter (browser)" icon="globe" href="/tutorials/install-freighter">
    Best for desktop and laptop use. Works with Chrome, Brave, Firefox, and Edge. Recommended if you mostly use Neko on a computer.
  </Card>
  <Card title="Lobstr (mobile)" icon="smartphone" href="/tutorials/install-lobstr">
    Best for phones. Easy to use, popular in Latin America, and supports USDC and XLM out of the box.
  </Card>
</CardGroup>

## Other options

Other compatible wallets include Hana, xBull, and Albedo. They all work with Neko. If you already have one of them set up, you can connect it from the Neko app. If not, we recommend starting with Freighter or Lobstr above.

<Note>You can use the same wallet on more than one device by importing your recovery phrase. Never share that phrase with anyone.</Note>
