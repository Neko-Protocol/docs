A **wallet** is an app that holds your money for you, on your phone or computer. Think of it like a bank account app, except there's no bank behind it. Instead, you're the only one who can open it and approve what happens with your money. Not Neko, not anyone else.

That also means you're the only one who can get back in if you lose access. There's no "forgot password" support line for a wallet, so keeping your recovery phrase (the backup code your wallet gives you when you set it up) safe really matters.

## Which wallets work with Neko

Every app like Neko runs on a specific system called a **network**, kind of like how an app is built for either iPhone or Android. Neko runs on a network called **Stellar**, so the wallet you use has to be built to work with Stellar too. A wallet made for a different network won't connect to Neko, the same way a card from one payment system won't work in a machine that only accepts a different one.

Wallets you can use with Neko today:

- **Freighter.** Works in your browser, best if you mostly use Neko on a computer. See [Install a wallet on browser](/tutorials/install-a-wallet#install-a-wallet-on-browser).
- **Lobstr.** An app for your phone, best for using Neko on mobile. See [Install a wallet on phone](/tutorials/install-a-wallet#install-a-wallet-on-phone).
- **Hana, xBull, and Albedo.** A few other wallets that also work with Neko. If you already use one of these, you can connect it directly, no need to switch.
