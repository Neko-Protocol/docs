## Report a bug

Open an issue at **[github.com/Neko-Protocol/Neko-DApp/issues](https://github.com/Neko-Protocol/Neko-DApp/issues)** with:

<Tabs>
  <Tab title="What to include">
    - Browser name and version
    - Wallet name and version
    - Network you used
    - Console errors (remove any secrets first; never paste seed phrases)
    - Transaction hash from a block explorer when relevant
    - Numbered steps so QA can reproduce the issue
  </Tab>
</Tabs>
